# random_songs_system

## 🎵 随机点歌系统

这是前[random songs系统](https://gitee.com/ji-or-ji/random_songs)的重制版。这一个功能丰富的Python命令行 ~~可能做图形化？~~ * 随机点歌系统，支持完整的歌曲管理、点歌人管理、多歌单支持、自动网页跳转和操作历史记录功能。

### ✨ 核心功能

#### 🎲 随机点歌

- 智能随机选择歌曲播放，支持防重复机制
- 自动过滤无效歌曲（空歌名）
- 显示完整的歌曲信息，包括点歌人
- 支持自动网页跳转到歌曲URL或B站搜索

#### 📊 统计分析

- 实时统计歌曲总数、有效/无效歌曲数量
- 点歌人排行榜统计
- 可视化数据展示

#### 👥 点歌人管理

- **添加点歌人** - 创建新的点歌人账户
- **删除点歌人** - 删除点歌人及其所有歌曲
- **修改点歌人** - 重命名点歌人姓名
- **查看点歌人列表** - 浏览所有点歌人

#### 🎵 歌曲管理

- **添加歌曲** - 添加新歌曲到库中
- **修改歌曲** - 编辑歌曲名称、歌手、外链URL或点歌人
- **删除歌曲** - 从库中移除指定歌曲
- **查看所有歌曲** - 浏览完整的歌曲列表

#### 📜 操作历史

- 完整的操作日志记录
- 时间戳记录所有重要操作
- 支持查看历史记录

#### 🎵 多歌单支持

- **创建歌单** - 创建新的歌单
- **切换歌单** - 在不同歌单之间切换
- **删除歌单** - 删除不需要的歌单
- **查看歌单信息** - 显示所有歌单的详细信息
- **从外部导入** - 支持从外部JSON文件导入歌单

#### 🌐 自动网页跳转

- **启用/禁用自动跳转** - 控制是否自动打开网页
- **跳转模式设置** - 支持URL跳转和B站搜索跳转
- **自定义延时** - 设置跳转前的等待时间（1-60秒）
- **智能跳转逻辑** - 优先跳转歌曲URL，无URL时根据配置跳转

#### 🔄 防重复功能

- **时间窗口防重复** - 在指定时间窗口内避免重复播放同一歌曲
- **播放记录管理** - 查看和管理播放历史
- **自动重置** - 所有歌曲播放后自动重置播放记录

### 🚀 快速开始

#### 系统要求

- **Python 3.6+**
- **支持的命令行终端** *（power shell、fish shell等用于运行程序本体，git bash用于一键部署...我后面可能会考虑对源代码编译，YIQIKAI（可选））*

#### 安装和运行

1. **将(deploy.sh)[deploy.sh]放置在目标文件夹下**

2. 在文件夹中打开终端，输入以下内容：

   ```bash
   bash deploy.sh
   ```

3. **确保文件结构正确**：

   ```text
   random_songs/
   ├── main_data/
   │   ├── play_list_1/                # 歌单1
   │   │   ├── play_lists_config.json # 歌单配置文件
   │   │   ├── history_records.log    # 历史记录文件
   │   │   ├── requester_list.json    # 点歌人数据
   │   │   ├── songs_list.json        # 歌单歌曲数据
   │   ├── play_list_2/                # 歌单2
   │   │   ├── play_lists_config.json # 歌单配置文件
   │   │   ├── history_records.log    # 历史记录文件
   │   │   ├── requester_list.json    # 点歌人数据
   │   │   ├── songs_list.json        # 歌单歌曲数据
   │   └ ...                           # 更多歌单...
   ├── src/                            # 主程序
   │   ├── main.py                    # 主函数
   │   ├── history_manager.py         #历史记录相关函数
   │   ├── 
   ├── LICENSE
   ├── README.md               # 说明文档
   └── test_*.py              # 测试文件
   ```

4. **运行程序**：

    - **使用终端**

   ```bash
   cd d:/random_songs
   python main_data/main.py
   ```

    - **或者你可以为主程序添加快捷方式，并设置python解释器为启动方式**

## 📁 数据文件格式

### 歌曲数据文件 (`songs_list.json`, `playlist_2.json`等)
```json
{
  "songs": [
    {
      "id": 1,
      "song_name": "知我",
      "artist": "",
      "url_list": "https://b23.tv/9QpZX1u",
      "requested_by": "王文洁"
    }
  ]
}
```

### 歌单配置文件 (`playlists_config.json`)
```json
{
  "current_playlist": "default",
  "playlists": {
    "default": {
      "name": "默认歌单",
      "description": "主歌单",
      "file_path": "main_data/songs_list.json",
      "created_at": "2025/09/06",
      "song_count": 60,
      "duplicate_prevention": {
        "enabled": true,
        "mode": "time_window",
        "time_window_hours": 1,
        "time_window_minutes": 0,
        "reset_on_all_played": true,
        "last_reset_time": "2025-09-07 09:43:44",
        "played_songs": []
      }
    }
  }
}
```

### 自动跳转配置文件 (`auto_jump_config.json`)
```json
{
  "auto_jump_enabled": true,
  "jump_mode": "search",
  "custom_url": "",
  "jump_delay": 3
}
```

### 历史记录文件 (`history_records.json`)
```json
[
  {
    "timestamp": "2025-08-31 14:39:22",
    "action": "添加歌曲",
    "details": "歌曲: 心动(beautiful) - 歌手: 伯贤 - 点歌人: 陈星彤",
    "result": "成功"
  }
]
```

## ⚠️ 注意事项  

### 文件管理

1. **备份重要数据**：在进行大量修改前建议备份数据文件
2. **不要手动编辑JSON**：使用程序功能管理数据，避免格式错误
3. **文件权限**：确保程序有读写数据文件的权限

### 使用建议

1. **定期查看统计**：了解歌曲库状态和点歌人活跃度
2. **清理无效数据**：定期使用统计功能查看无效歌曲
3. **利用历史记录**：追踪所有操作便于审计
4. **使用多歌单**：为不同场景创建专用歌单

### 自动跳转使用

1. **注意隐私**：自动跳转会打开浏览器，请注意使用环境
2. **调整延时**：根据需要设置合适的跳转等待时间
3. **URL验证**：确保自定义URL格式正确

## 🐛 故障排除

### 常见问题

1. **程序无法启动**
   - 检查Python是否正确安装：`python --version`
   - 确认文件路径正确

2. **文件读写错误**
   - 检查文件权限
   - 确认文件没有被其他程序占用

3. **数据损坏**
   - 不要手动编辑JSON文件
   - 使用备份文件恢复

4. **操作失败**
   - 检查磁盘空间
   - 确认有足够的权限

5. **自动跳转不工作**
   - 检查浏览器是否被阻止
   - 确认网络连接正常

### 获取帮助

如遇到问题，请检查：

- Python版本是否符合要求 (3.6+)
- 所有必要文件是否在正确目录
- 文件权限是否足够
