# 随机点歌系统 · 单元测试

## 测试结构

- `test_core.py` — 核心逻辑：配置合并、初始化、歌曲数据、防重复、歌单
- `test_qq_importer.py` — QQ 歌单 ID 解析、导入与去重（全部本地打桩，不联网）

## 运行

```bash
python run_tests.py          # 一键运行全部
python -m unittest discover tests
python -m unittest tests.test_core
```

## 覆盖范围

1. **配置与初始化**：默认值深合并、首次运行创建默认歌单、重复初始化幂等
2. **歌曲**：旧字段（`url_list`）兼容、统计、增删
3. **防重复**：整轮不重复、时间窗口拦截、关闭重置时返回 None、坏记录容错、记录规模有上界
4. **歌单**：ID 清洗与去重、数据文件创建
5. **QQ 歌单**：ID 提取、导入与按「歌名+歌手」去重、未配置时抛错

## 设计原则

- **隔离**：每个用例把数据根目录指向临时目录（`paths.set_data_root`），互不影响，也不动真实数据
- **离线**：网络相关一律打桩，测试不需要外网
- **中文描述**：用例与断言贴合业务语义，便于阅读
